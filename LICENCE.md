## 🧩 About

**Call of Duty Black Ops 7 catalog Menu** is a curated list of Call of Duty Black Ops 7 open-source tools:

- **Overlays** — on-screen helpers, layout notes, menu customizer, process monitor
- **Quality-of-Life Helpers** — loadout presets, settings manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### 🎮 Gameplay Helpers
- Loadout Presets — save and switch custom loadouts
- HUD Customizer — toggle HUD elements and colors
- Sensitivity Tuner — fine-tune mouse and controller settings

- catalog Menu — preview locked items in single-player
